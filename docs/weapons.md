# 《余烬回环》武器系统设计

> 版本：v0.6
> 更新日期：2026-11-18
> 相关文档：[机制](mechanics.md) · [接口与数据契约](interfaces.md) · [动画引擎](animation.md)

本文件定义武器分类、攻击范围与伤害模型、武器等级成长、特殊武器的属性绑定规则。逻辑实现以 `game/systems/weapons.py` + `game/data/weapons.json` 为准。

## 1. 武器分类

| 类别 | 定位 | 攻击范围（判定框宽×高） | 伤害档位 | 攻速 | 特性 |
| --- | --- | --- | --- | --- | --- |
| 太刀 tachi | 快攻 | 32×22 | 中（10） | 1.3 | 近距高频，三段连击末段加重 |
| 长剑 longsword | 均衡 | 40×26 | 中（12） | 1.0 | 中距标准三段连击，末段击退 |
| 斩马刀 zhanmadao | 重斩 | 56×30 | 高（24） | 0.65 | 远距大范围重斩，两段连击，大击退 |
| 盾牌 shield | 防反 | 28×24 | 低（4） | 1.1 | 盾击减半鼓励防反；格挡窗口 ×2；防反伤害保留（counter_multiplier 3.0） |
| 弓箭 bow | 远程 | 箭矢 400px/s × 0.6s = 半屏 | 中低（9） | 0.8 | 发射玩家箭矢；无格挡，只能闪避 |

范围规则：

- 判定框从角色碰撞框朝向一侧伸出；宽 = 有效攻击距离，高 = 纵向覆盖。
- 远程武器（`projectile` 字段）不产生近战判定框，active 期发射投射物，命中走 `CombatSystem` 同一结算。
- 格挡窗口 = `PARRY_WINDOW × parry_scale`（默认 1.0；盾牌 2.0；弓 0.0 即禁用）。
- 防反增益 = `counter_multiplier`（默认 1.5；盾牌 3.0，配合减半的盾击保留 12 点防反伤害，鼓励格挡）。
- 数值可随区域深度微调，但类别间的范围/攻速相对关系不变。

## 2. 伤害模型

```text
单次攻击力 = 武器基础伤害
            × (1 + level_scale × (等级 − 1))
            × (1 + Σ 属性绑定加成)
            × (反击增益 ×counter_multiplier，若触发；默认 1.5)
```

- 暴击（默认 5% / ×1.5）与护甲减免在 `CombatSystem` 中结算，见机制文档 1.4。
- 属性绑定加成在**起手瞬间**取值：挥砍过程中血量变化不影响本次伤害。
- 攻击范围、帧窗口（前摇/判定/后摇）均取自 `weapons.json`，动画只做表现。

## 3. 武器等级

| 等级 | 伤害倍率 | 说明 |
| --- | --- | --- |
| Lv1 | ×1.00 | 初始 |
| Lv2 | ×1.10 | |
| Lv3 | ×1.20 | |
| Lv4 | ×1.30 | |
| Lv5 | ×1.40 | 上限 |

- JSON 中声明 `max_level` 与 `level_scale`；**等级属于武器实例**，随掉落/余烬祠生成，不写死在基础表里。
- 升级消耗烬屑，在余烬祠进行（M4 实现）；升级只影响伤害倍率，不改变帧窗口与范围。
- 掉落生成时按区域深度决定初始等级（区域 1：Lv1–2，区域 2：Lv2–3，依此类推）。

## 4. 属性绑定（特殊武器）

绑定词条读取玩家当前资源，按下式计算：

```text
加成 = max_bonus × ratio
```

| stat | ratio | 含义 |
| --- | --- | --- |
| `missing_hp` | 1 − HP/最大HP | 血越少越强（背水） |
| `hp` | HP/最大HP | 满血增益 |
| `stamina` | 当前体力/最大体力 | 体力越满越强 |
| `mana` | 当前蓝条/最大蓝条 | 蓝越满越强 |

- 多条绑定可叠加（Σ），总加成上限由 `max_bonus` 控制，避免指数膨胀。
- 绑定加成与词缀增伤、暴击、护甲为独立乘区/加区，结算顺序见机制 1.4。
- 示例：
  - **背水长刃**：`{"stat": "missing_hp", "max_bonus": 0.8}` → 1 HP 时伤害 +80%。
  - **疾影双匕**：`{"stat": "stamina", "max_bonus": 0.35}` → 满体力 +35%，与冲刺消耗形成取舍。
  - **余烬法杖**：`{"stat": "mana", "max_bonus": 0.5}` → 满蓝 +50%，鼓励控蓝。

## 5. 数据契约（weapons.json 扩展）

```json
{
  "schema_version": 1,
  "weapons": {
    "desperate_edge": {
      "name_key": "weapon.desperate_edge.name",
      "desc_key": "weapon.desperate_edge.desc",
      "class": "spear",
      "base_damage": 9,
      "attack_speed": 1.0,
      "combo": [9, 10, 14],
      "hitbox": [44, 18],
      "windup_ms": 70,
      "active_ms": 90,
      "recovery_ms": 150,
      "knockback": 140,
      "max_level": 5,
      "level_scale": 0.1,
      "scaling": [{"stat": "missing_hp", "max_bonus": 0.8}],
      "tags": ["melee", "special"]
    }
  }
}
```

新增字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| max_level | number | 武器等级上限（默认 5） |
| level_scale | number | 每级伤害增量（默认 0.1） |
| scaling | object[] | 属性绑定列表，`{stat, max_bonus}` |

运行时字段（不写入 JSON）：`id`、`level`、词缀实例。

## 6. 与玩法/UI 的接入

- 玩家起手时通过 `weapon_damage(weapon, player)` 计算攻击力，反击增益最后乘算。
- 主角全程只持一把武器：新开局先进入兵器选择界面（`game/scenes/weapon_select.py`，A/D 或鼠标选择，J/Enter 确认，ESC 返回标题）；`Game.start_run(weapon_id)` 记录 `last_weapon_id`。存活时 R 快速重开沿用当前武器；死亡后 R 或结算页「再入回环」重新进入选择界面（预选上局武器）。
- 局内不可更换武器：客栈武器架仅为场景装饰；换武器只发生在开局与死亡重开的选择界面。HUD 只显示武器名、等级、实时攻击力与加成（`hud_state.weapon.slot/slots` 固定 1/1，保留契约字段）。
- 背包/装备对比由 C 实现，读取武器实例的 `id/level/scaling` 与 B 提供的物品实例数据。
- 武器专属动作已接入：按武器 id 播放 `attack_<id>_windup/active/recovery`（太刀/长剑/斩马刀/盾牌/弓箭），帧率与各武器毫秒窗口对齐，详见 [动画引擎](animation.md) 1.1。
