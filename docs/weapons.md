> 版本：v0.1
> 更新日期：2026-11-18

本文件定义武器分类、攻击范围与伤害模型、武器等级成长、特殊武器的属性绑定规则。逻辑实现以 `game/systems/weapons.py` + `game/data/weapons.json` 为准。

范围规则：

- 判定框从角色碰撞框朝向一侧伸出；宽 = 有效攻击距离，高 = 纵向覆盖。
- MVP 只实现近战判定框（直剑/双匕/重锤/长枪/背水长刃/法杖近战模板），弓/轮刃走投射物。
- 数值可随区域深度微调，但类别间的范围/攻速相对关系不变。

## 2. 伤害模型

```text
单次攻击力 = 武器基础伤害
            × (1 + level_scale × (等级 − 1))
            × (1 + Σ 属性绑定加成)
            × (反击增益 ×1.5，若触发)
```

- 暴击（默认 5% / ×1.5）与护甲减免在 `CombatSystem` 中结算，见机制文档 1.4。
- 属性绑定加成在**起手瞬间**取值：挥砍过程中血量变化不影响本次伤害。
- 攻击范围、帧窗口（前摇/判定/后摇）均取自 `weapons.json`，动画只做表现。

## 3. 武器等级

| 等级 | 伤害倍率 | 说明 |
| --- | --- | --- |
| Lv1 | ×1.00 | 初始 |
| Lv2 | ×1.10 | |
| Lv3 | ×1.20 | |
| Lv4 | ×1.30 | |
| Lv5 | ×1.40 | 上限 |

- JSON 中声明 `max_level` 与 `level_scale`；**等级属于武器实例**，随掉落/祭坛生成，不写死在基础表里。
- 升级消耗火种，在祭坛进行（M4 实现）；升级只影响伤害倍率，不改变帧窗口与范围。
- 掉落生成时按区域深度决定初始等级（区域 1：Lv1–2，区域 2：Lv2–3，依此类推）。

## 4. 属性绑定（特殊武器）

绑定词条读取玩家当前资源，按下式计算：

```text
加成 = max_bonus × ratio
```

| stat | ratio | 含义 |
| --- | --- | --- |
| `missing_hp` | 1 − HP/最大HP | 血越少越强（背水） |
| `hp` | HP/最大HP | 满血增益 |
| `stamina` | 当前体力/最大体力 | 体力越满越强 |
| `mana` | 当前蓝条/最大蓝条 | 蓝越满越强 |

- 多条绑定可叠加（Σ），总加成上限由 `max_bonus` 控制，避免指数膨胀。
- 绑定加成与词缀增伤、暴击、护甲为独立乘区/加区，结算顺序见机制 1.4。
- 示例：
  - **背水长刃**：`{"stat": "missing_hp", "max_bonus": 0.8}` → 1 HP 时伤害 +80%。
  - **疾影双匕**：`{"stat": "stamina", "max_bonus": 0.35}` → 满体力 +35%，与冲刺消耗形成取舍。
  - **余烬法杖**：`{"stat": "mana", "max_bonus": 0.5}` → 满蓝 +50%，鼓励控蓝。

## 5. 数据契约（weapons.json 扩展）

```json
{
  "schema_version": 1,
  "weapons": {
    "desperate_edge": {
      "name_key": "weapon.desperate_edge.name",
      "desc_key": "weapon.desperate_edge.desc",
      "class": "spear",
      "base_damage": 9,
      "attack_speed": 1.0,
      "combo": [9, 10, 14],
      "hitbox": [44, 18],
      "windup_ms": 70,
      "active_ms": 90,
      "recovery_ms": 150,
      "knockback": 140,
      "max_level": 5,
      "level_scale": 0.1,
      "scaling": [{"stat": "missing_hp", "max_bonus": 0.8}],
      "tags": ["melee", "special"]
    }
  }
}
```

新增字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| max_level | number | 武器等级上限（默认 5） |
| level_scale | number | 每级伤害增量（默认 0.1） |
| scaling | object[] | 属性绑定列表，`{stat, max_bonus}` |

运行时字段（不写入 JSON）：`id`、`level`、词缀实例。

## 6. 与玩法/UI 的接入

- 玩家起手时通过 `weapon_damage(weapon, player)` 计算攻击力，反击增益最后乘算。
- 练习场：武器快捷槽 6 把轮换（剑/特殊剑/锤/枪/匕/杖各一），`Q` 切换；HUD 显示槽位、武器名、等级、实时攻击力与属性加成百分比（掉血时绝境之锋数值会上涨）。
- 背包/装备对比由 C 实现，读取武器实例的 `id/level/scaling` 与 B 提供的物品实例数据。
- 武器专属动作已接入：按 `class` 播放 `attack_<class>_windup/active/recovery`（剑斩/匕刺/锤砸/枪突/杖击），帧率与各武器毫秒窗口对齐，详见 [动画引擎](animation.md) 1.1。
