## 1. 世界观与回环规则

**青篁岭**是南岭竹海深处的一条古驿道，往来江湖客必经此地。岭心有一盏**烬心灯**，相传由前朝铸剑师以自身心火铸成，灯下镇着"**无相**"——一个靠吞食姓名与记忆活着的古老存在。

灯在，岭上人便记得自己是谁；灯灭，名字被吃，人就成了只会重复生前动作的妖物。

回环开始的那一夜，后世称为"**灯灭之夜**"：子时灯焰倒流，整条青篁岭被锁进不断重演的一夜。竹坞客栈里正在设宴的江湖客、跑堂、酒保，全被灯火烧去了名字，成了**酒坛魈**与**纸人跑堂**。

烬心灯同时承担三重身份：

1. **灯火**：岭上人家的心火之源，也是妖物不敢近身的原因。
2. **封印**：灯下压着无相，名字是封印的锁。
3. **循环核心**：灯以岭上记忆为油，油反复烧，夜便反复回环。

回环规则（后续剧情与系统设计都以此为准）：

1. **触发**：子时灯焰倒流，青篁岭的时间回到"灯灭之夜"。
2. **重置**：山道、客栈复原，人却变成妖物；被烧掉的记忆凝成"余烬"。
3. **代价**：每一次回环都会永久烧掉一个名字，包括人名、旧事与情义。
4. **例外**：持有"烬心"的人可以在余烬祠重铸身体，但每次重铸都会丢一段情景记忆。
5. **锚点**：岭外的**余烬祠**是灯婆用分灯守出的"环外小屋"，不在回环范围内，是唯一稳定的落脚点。
6. **出口**：烬心地宫的灯芯是回环的源头，也是唯一能终止循环的地方。

地理结构（由外至内）：

```text
余烬祠（岭外） → 青篁岭·竹坞客栈 → 药王谷·腐草洞 → 寒山寺·沉钟楼 → 烬心地宫（灯芯）
```

## 2. 主角设定

### 2.1 基本信息

| 项目 | 设定 |
| --- | --- |
| 称呼 | **无名客**（江湖上对"那个每晚都从岭下走来的人"的叫法）；真名"**沈烬**"，直到剧情后段才被重新记起 |
| 身份 | 三年前在竹坞客栈失踪的游侠；灯灭之夜死在客栈后院 |
| 身体 | 灯婆以烬心灯的残焰与他的旧衣重塑的躯体，左胸嵌着"烬心" |
| 外貌 | 青灰长衫、斗笠压眉，面容在灯火下始终看不真切；左胸一点灯焰是全身唯一的高饱和光源；腰间挂一截烧焦的剑鞘 |
| 初始武器 | 残焰剑（他生前留在客栈的佩剑，剑上铭文被灯火烧去了半截） |
| 台词 | 全程无台词；用点头、抱拳、按剑、摘下斗笠等动作表达态度 |
| 核心动机 | 前期："客栈里还剩下谁"；中期："我到底叫什么"；后期：决定这盏灯与自己的去留 |

### 2.2 能力来源

- **烬心**：烬心灯的一点灯芯，是主角能不断重铸的原因，也是"余烬"的来源。
- **重铸**：死后在余烬祠重新凝聚身体。程序记忆（武艺、身法）保留，情景记忆（上一轮发生了什么）丢失。
- **余烬吸收**：斩杀妖物、探索房间会收集逸散的烬屑，即局外货币"余烬"。
- **兵器记忆**：主角不"拥有"兵器，而是借烬心读取兵刃上残留的旧主记忆，因此能立刻上手任何捡到的兵器。这为肉鸽式随机掉落提供了剧情解释。
- **烬心示警**：靠近重要记忆碎片时，胸口灯焰会脉动，用于引导探索与隐藏剧情。

### 2.3 记忆规则（重要设定）

- **武艺记忆保留**：每次重铸后仍会出剑、翻纵、运劲，对应玩家的操作熟练度与永久成长。
- **情景记忆丢失**：不记得上一轮见过谁、做过什么，因此同一句 NPC 台词可以有"第一次听"和"似曾相识"两种版本。
- **代价递增**：每次重铸都会让烬心更接近熄灭，也会烧掉岭上更多名字。玩家的每一次死亡都在推进世界的损耗。
- **叙事接口**：死亡次数会被 NPC 记住，余烬祠会刻下死亡计数，部分场景会随死亡次数发生固定变化。

### 2.4 性格与表演

主角不是传统大侠，也不是嗜杀者。他沉默、守规矩，对世界保留好奇：会停下来观察重复迎客的纸人跑堂，会向倒下的妖物抱拳，会在听到"沈烬"这个名字时停顿半秒。玩家通过这些细节感受到他逐渐"变回一个人"。

### 2.5 角色弧光

1. **问路**：最初只把自己当作灯婆派上岭的刀，目标是把客栈的门推开。
2. **疑身**：发现自己不是第一个无名客，开始怀疑自己是"本人"还是"灯焰捏出来的影子"。
3. **认同**：接受身体是重铸的，但选择与记忆中的自己连续，愿意继续上岭。
4. **选择**：在灯芯前决定熄灯、续灯或以身代灯，完成从"被灯牵扯的亡魂"到"自己做主的人"的转变。

### 2.6 弱点与伏笔

- 烬心每次重铸都会变暗一点，暗示结局 C 的自我牺牲。
- 斗笠下的面孔无人记得；结局 C 中真名被叫出时，会第一次出现"摘下斗笠"的正面意象。
- 主角对"钟声"有本能的恐惧，第三幕揭示：灯灭之夜，寒山寺的钟声正是灯焰倒流的引子。

## 3. 关键 NPC 与回声

| 角色 | 身份 | 与主角的关系 | 剧情作用 | 结局走向 |
| --- | --- | --- | --- | --- |
| 灯婆 | 余烬祠守灯人，前朝守灯一脉最后一人 | 救命恩人，也是把他推入回环的人 | 用禁忌灯术把主角残躯与残焰做成烬心；知道全部真相；刻薄源于愧疚 | A：留在岭外；B：继续守祠；C：第一次叫出真名"沈烬" |
| 墨蛾 | 烬屑凝成的蛾形存在 | 中立观察者，逐渐产生共情 | 收集被吃掉的名字；负责图鉴与剧情整理；揭示"死亡会烧掉别人的名字" | C：带着主角的故事飞出岭外 |
| 货郎老柴 | 活在回环夹缝里的跑单帮货郎 | 交易对象，少数还会开玩笑的人 | 提供货物、情报与岭外世界的线索；证明"环外"确实存在 | 离开青篁岭，暗示续作 |
| 守关人 | 第七次回环的无名客回声 | 前辈，与主角同源 | 放弃上岭，守在岭口；测试主角；负责开启难度与路线选择 | 见证主角走到最后，或再次留下守关 |

**回声设定**：每次无名客死亡，死亡地点会留下一具"回声"——没有意识的残影，重复着死亡前的最后一个动作。大多数回声只是环境叙事，少数会因记忆堆积而变成精英妖物。守关人与守钟僧都是早期回声，前者保留理智，后者已经被回环磨成怪物。

## 4. 剧情走向

### 4.1 序章：岭下醒来

1. 主角在余烬祠醒来，灯婆把残焰剑丢给他："上岭。看看客栈里还剩下谁。"
2. 教学关：移动、跳跃、冲刺、普攻，穿过祠外的竹径。
3. 进岭石桥处发生剧情性坍塌，主角第一次死亡（必发但温和，不惩罚资源）。
4. 在余烬祠重铸，玩家第一次学会"死亡不是结束"；灯婆："记住胸口那点火。别的都可以忘。"
5. 岭口山门在身后合拢，只能沿竹海小径继续向前——正式进入第一幕。

### 4.2 第一幕：青篁岭·竹坞客栈（回环 1–3 次）

- 场景展示回环的残酷：同一桌酒席反复开席，纸人跑堂一遍遍上菜，座上客早已变成酒坛魈。
- 在客栈廊下遇见货郎老柴，第一次交易，得知"灯不是那晚才灭的"。
- 拾取记忆碎片 1：客栈牌匾背后刻着四个字——"灯在人在"。
- 精英怪**醉拳魈**守在二楼横梁，击败后掉落第一件稀有兵器。
- Boss **焦面掌柜**守卫客栈后门。战前他说："客官，打尖还是住店？您上次的账，还没结呢。"——第一次明确暗示回环。
- 获得"灯印·门"，后门开启，通往药王谷。

### 4.3 第二幕：药王谷·腐草洞（回环 4–8 次）

- 谷中药材被灯灰污染，长成腐草；洞里的"药人"是被泡在药缸里续命的江湖客。
- 第一次遇见墨蛾。它问："你知道你每次死，岭上就少一个名字吗？"
- 主角在洞窟深处发现一具与自己一模一样的无面尸体——上一轮的回声。
- 触碰回声，看到记忆碎片 2：灯婆在余烬祠里把一点灯芯按进一具残躯的胸口。
- Boss **药人母**。战后获得"灯印·忆"。
- 墨蛾告知：名字是灯的油，回环不是故障，而是维持封印的方式。

### 4.4 第三幕：寒山寺·沉钟楼（回环 9–15 次）

- 寺中铜钟刻满历次回环的日期，最早的一道刻痕已经无法辨认。
- 守关人（第七次回声）可选战斗。战胜后他承认：主角是沈烬，死于灯灭之夜。
- Boss **守钟僧**（第二十三次回声）。他放弃上岭，以敲钟压住回环的声响，最终被钟声吞掉；战斗中不断切换招式，模仿主角自己用过的兵器。
- 战胜后守钟僧短暂清醒，交出"灯印·时"："替我看看灯芯。"
- 剧情揭示：主角原本的身体仍在灯芯旁，现在的身体只是灯焰重铸的影子。主角第一次面对"我是谁"的问题。

### 4.5 第四幕：烬心地宫（终局）

- 灯婆借分灯现身，坦白全部真相：她没能救下沈烬，于是用禁灯之术造出无名客；每次回环都在烧掉岭上的名字，而她却一次次把他送上去。
- 最终 Boss **无相**：以主角原本的身体与面容为核心，三阶段战斗。战斗过程中穿插记忆闪回，包括灯灭之夜与灯婆的争执。
- 战斗结束后，灯芯向主角提出选择：默认可熄灯；首次通关后解锁续灯。
- 若集齐三枚"灯印"，灯印会在灯芯前共鸣，解锁"以身代灯"的真结局选项。

## 5. 结局与后日谈

| 结局 | 条件 | 过程 | 结果 |
| --- | --- | --- | --- |
| A. 熄灯 | 默认 | 主角拔下灯芯，积压的记忆一次性回流 | 岭上人短暂恢复清醒后随青篁岭沉入夜雾；封印松动，无相在竹海下睁开眼（续作伏笔）；主角拾起斗笠离开 |
| B. 续灯 | 首次通关后可选 | 把灯芯放回原处，吸收残余余烬 | 回环继续，主角成为新的守灯人，逐渐失去自己的名字；解锁灯焰热度与后续难度 |
| C. 以身代灯 | 集齐 3 枚灯印 | 主角走进灯芯，以自己的烬心替代灯芯 | 回环终止，岭上人恢复名字与死亡；墨蛾带着主角的故事飞离；灯婆第一次叫出"沈烬"；余烬祠空了，只剩一点火星 |

后日谈设计：

- 通关任意结局后，余烬祠的对话随结局变化，NPC 会记得玩家选择。
- 灯焰热度在剧情上是"回环加深"：妖物更强，NPC 也会说出平时不会说的话。
- 图鉴 100% 后解锁一段隐藏文本：墨蛾写下的《无名客纪事》，补全主角真名与灯婆的过去。

## 6. 叙事方式与对白样例

叙事原则：

- **环境叙事优先**：纸人跑堂重复上菜、铜钟上的刻痕、客栈牌匾背面的字、余烬祠的死亡计数，都是剧情。
- **短对话**：NPC 每次回归只说 1–2 句，随进度与死亡次数变化，不做长过场。
- **物品文本**：兵器、遗物、记忆碎片附带短背景，拼出世界观。
- **Boss 台词**：每个 Boss 战开场与转阶段各 1 句，强化角色而非打断节奏。
- **死亡是剧情**：死亡次数会影响 NPC 台词、余烬祠刻痕和部分场景演出。

对白样例：

- 灯婆（初次）："又醒了？剑在门口。别死得太快。"
- 灯婆（死亡 10 次后）："你姓什么来着……罢了，先上岭。"
- 墨蛾（初次）："你身上有灯灰。活人，死人，还是别的什么？"
- 墨蛾（第二幕后）："你每死一次，我就多记一个名字。猜猜今晚少了谁？"
- 货郎老柴："活人？稀客。死人我见得多，会还价的死人你是头一个。"
- 焦面掌柜（战前）："客官，打尖还是住店？您上次的账，还没结呢。"
- 守关人（战前）："过去可以。先告诉我——你是第几个我？"
- 守钟僧（战败后）："别这样看我。我只是……先走了一步。"
- 灯婆（结局 C）："沈烬。……对，你叫沈烬。"

## 7. 主题与基调

- **主题**：名字与身份、信义与牺牲、循环与自由、成长的代价。
- **基调**：悲凉但不绝望；灯火带来温暖；货郎老柴提供克制的黑色幽默；恐怖元素点到为止。
- **视觉叙事**：用重复迎客的妖物表现"被困住的人"，用钟上刻痕表现"被消耗的历史"，用无面尸体表现"被遗忘的名字"。
- **内容边界**：不做过度的血腥表现，不影射现实宗教与历史；寺、观、驿站的设定均为架空，全部角色与名词原创。

## 8. 剧情与玩法系统的结合

| 系统 | 剧情解释 |
| --- | --- |
| 死亡与重铸 | 死亡是正典；每次死亡会在原地留下回声，并推进 NPC 台词 |
| 余烬（局外货币） | 被烧掉的记忆烬屑；强化=主角"记起"武艺本能 |
| 兵器装备 | 兵器记忆：烬心读取兵刃上的旧主记忆，解释随机掉落与即时上手 |
| 词缀 | 旧主残念：同一兵刃因承载的记忆不同而呈现不同特性 |
| 灯印 | 三个 Boss 各持一枚，是通向真结局的钥匙 |
| 灯焰热度 | 回环加深；妖物与 NPC 都"记得"更多次循环 |
| 图鉴 | 墨蛾收集的名字与故事；100% 解锁隐藏文本 |
