## 1. 世界观与回环规则

**灰烬环岛**曾是旧王国的能源中心。岛中央的**永恒熔炉**抽取地心余火，为整片大陆供能。回环开始之夜，熔炉失控，整座岛被锁进不断重置的时间循环：居民的灵魂被反复灼烧，失去记忆，变成只会重复生前动作的"烬民"。

熔炉同时承担三重身份：

1. **能源**：旧王国的动力核心。
2. **封印**：熔炉下方镇压着"无光者"——一种以记忆为食的古老存在。
3. **循环核心**：熔炉以全岛记忆为燃料维持封印，燃料反复燃烧，导致时间不断回环。

回环规则（后续剧情与系统设计都以此为准）：

1. **触发**：炉心失衡时，整座岛的时间回到"熔炉失控之夜"。
2. **重置**：物理世界复原，但灵魂被灼烧成烬民；被烧掉的记忆成为"记忆灰烬"。
3. **代价**：每一次回环都会永久损耗岛上的记忆，包括人名、历史与情感。
4. **例外**：持有"余烬之心"的人可以在祭坛重构身体，但每次重构都会丢失一部分情景记忆。
5. **锚点**：熔炉祭坛是炉妪用旧时代技术造出的"环外小屋"，不在回环范围内，是唯一稳定的落脚点。
6. **出口**：熔炉之巅的炉心是回环的源头，也是唯一能终止循环的地方。

地理结构（由下至上）：

```text
熔炉祭坛（环外） → 灰烬城郊 → 菌光洞窟 → 沉钟回廊 → 熔炉之巅（炉心）
```

## 2. 主角设定

### 2.1 基本信息

| 项目 | 设定 |
| --- | --- |
| 称呼 | **余烬行者**（烬民给的名字）；真名"**燧**"，直到剧情后段才被重新记起 |
| 身份 | 旧王国最后一任守炉人的学徒；回环开始之夜死于炉心事故 |
| 身体 | 炉妪用他的残躯与炉心碎片重塑的无面躯体，左胸嵌着"余烬之心" |
| 外貌 | 灰白陶土般的皮肤，面部没有五官；左胸火种是全身上下唯一的高饱和光源；披着烧焦的短披风，右臂有熔痕 |
| 初始武器 | 断燧直剑（炉妪给他的旧物） |
| 台词 | 全程无台词；用点头、摇头、停顿、触摸火种等动作表达态度 |
| 核心动机 | 前期："上去看看"；中期："我到底是谁"；后期：决定这座岛与自己的结局 |

### 2.2 能力来源

- **余烬之心**：熔炉炉心的一块碎片，是主角能不断重生的原因，也是"余烬"货币的来源。
- **重构**：死亡后在祭坛重新凝聚身体。程序记忆（战斗本能、操作熟练度）保留，情景记忆（上一轮发生了什么）丢失。
- **余烬吸收**：击杀敌人、探索房间会收集逸散的记忆灰烬，即局外货币"余烬"。
- **武器记忆**：主角不"拥有"武器，而是通过火种读取武器上的使用记忆，因此能立刻上手任何捡到的武器。这为肉鸽式随机掉落提供了剧情解释。
- **火种感知**：靠近重要记忆碎片时，胸口火种会脉动，用于引导探索与隐藏剧情。

### 2.3 记忆规则（重要设定）

- **程序记忆保留**：每次重生后仍会战斗、跳跃、使用技能，对应玩家的操作熟练度与永久成长。
- **情景记忆丢失**：不记得上一轮见过谁、做过什么，因此同一句 NPC 台词可以有"第一次听"和"似曾相识"两种版本。
- **代价递增**：每次重构都会让余烬之心更接近熄灭，也会烧掉岛上更多记忆。玩家的每一次死亡都在推进世界的损耗。
- **叙事接口**：死亡次数会被 NPC 记住，祭坛会刻下死亡计数，部分场景会随死亡次数发生固定变化。

### 2.4 性格与表演

主角不是传统英雄，也不是嗜杀者。他沉默、固执，对世界保留好奇：会停下来观察重复动作的烬民，会对 NPC 的请求点头，会在听到"燧"这个名字时停顿半秒。玩家通过这些细节感受到他逐渐"变回一个人"。

### 2.5 角色弧光

1. **工具**：最初只把自己当作炉妪派出去的工具，目标是把门推开。
2. **怀疑**：发现自己不是第一个余烬行者，开始怀疑自己是"本人"还是"复制品"。
3. **认同**：接受身体是复制品，但选择与记忆中的自己连续，愿意继续攀登。
4. **选择**：在炉心前决定熄灭、重启或取代熔炉，完成从"被创造的工具"到"做决定的人"的转变。

### 2.6 弱点与伏笔

- 火种每次重生都会变暗一点，暗示结局 C 的自我牺牲。
- 无面意味着身份的流失；结局 C 中真名被记起时，会第一次出现"脸"的意象。
- 主角对"钟声"有本能的恐惧，第三幕揭示：回环开始之夜，炉心事故的警报就是钟声。

## 3. 关键 NPC 与回声

| 角色 | 身份 | 与主角的关系 | 剧情作用 | 结局走向 |
| --- | --- | --- | --- | --- |
| 炉妪 | 旧王国最后的守炉人，主角的师父 | 救命恩人，也是把他推进循环的人 | 用禁忌术把主角残躯与炉心碎片做成火种；知道全部真相；刻薄源于愧疚 | A：留在沉岛；B：继续守祭坛；C：第一次叫出真名"燧" |
| 墨蛾 | 记忆灰烬聚成的蛾形存在 | 中立观察者，逐渐产生共情 | 收集被烧掉的名字；负责图鉴与剧情整理；揭示"死亡会烧掉别人的记忆" | C：带着主角的故事飞出岛外 |
| 拾荒商 | 活在回环夹缝里的走私者 | 交易对象，少数还会开玩笑的人 | 提供商品、情报与岛外世界的线索；证明"环外"确实存在 | 离开环岛，暗示续作 |
| 守门人 | 第 7 次回环的余烬行者回声 | 前辈，与主角同源 | 放弃攀登，守在城郊入口；测试主角；负责开启难度与路线选择 | 见证主角走到最后，或再次留下守门 |

**回声设定**：每次余烬行者死亡，死亡地点会留下一具"回声"——没有意识的残影，重复着死亡前的最后一个动作。大多数回声只是环境叙事，少数会因记忆堆积而变成精英敌人。守门人和守夜者都是早期回声，前者保留理智，后者已经被回环磨成怪物。

## 4. 剧情走向

### 4.1 序章：灰烬中醒来

1. 主角在祭坛醒来，炉妪把断燧直剑丢给他："上去看看。别死得太快。"
2. 教学关：移动、跳跃、冲刺、普攻，穿过祭坛外的废墟。
3. 城郊断桥处发生剧情性坍塌，主角第一次死亡（必发但温和，不惩罚资源）。
4. 在祭坛重构，玩家第一次学会"死亡不是结束"；炉妪："记住胸口那点火。别的都可以忘。"
5. 城门关闭，需要从侧面绕行——正式进入第一幕。

### 4.2 第一幕：灰烬城郊（回环 1–3 次）

- 场景展示回环的残酷：同一群烬民重复同一个动作，钟声每天在同一时刻响起。
- 遇见拾荒商，第一次交易，得到"熔炉不是从那天才坏的"的情报。
- 拾取记忆碎片 1：熔炉铭文"火不是从熔炉开始的"。
- 精英怪焚炉卫挡路，击败后掉落第一件稀有武器。
- Boss **焚炉门卫**守卫第一道熔炉闸门。战斗结束后它说："你上次也是这么打的。"——第一次明确暗示循环。
- 获得"余火之证·门"，闸门开启，进入洞窟。

### 4.3 第二幕：菌光洞窟（回环 4–8 次）

- 洞窟的孢子是记忆灰烬的畸变体，会让人看到不属于自己的记忆。
- 第一次遇见墨蛾。它问："你知道你每次死，岛上就少一个名字吗？"
- 主角在洞窟深处发现一具与自己一模一样的无面尸体——上一轮的回声。
- 触碰回声，看到记忆碎片 2：炉妪在祭坛前把一枚发光的碎片按进一具残躯的胸口。
- Boss **孢子母体**。战后获得"余火之证·忆"。
- 墨蛾告知：记忆是熔炉的燃料，回环不是故障，而是维持封印的方式。

### 4.4 第三幕：沉钟回廊（回环 9–15 次）

- 钟楼刻满历次回环的日期，最早的一道刻痕已经无法辨认。
- 守门人（第 7 次回声）可选战斗。战胜后他承认：主角是守炉人的学徒，回环开始之夜死在炉心。
- Boss **钟楼守夜者**（第 23 次回声）。战斗中它不断切换招式，模仿主角自己用过的武器。
- 战胜后守夜者短暂清醒，交出"余火之证·时"："替我看看炉心。"
- 剧情揭示：主角原本的身体仍在炉心，现在的身体只是火种重塑的复制品。主角第一次面对"我是谁"的问题。

### 4.5 第四幕：熔炉之巅（终局）

- 炉妪通过祭坛共鸣现身，坦白全部真相：她没能救下学徒，于是用禁忌术制造了余烬行者；每次回环都在消耗岛上的记忆，而她却一次次把主角送上去。
- 最终 Boss **熔炉之心**：以主角原本的身体为核心，三阶段战斗。战斗过程中穿插记忆闪回，包括回环开始之夜与炉妪的争吵。
- 战斗结束后，炉心向主角提出选择：默认可熄灭熔炉；首次通关后解锁重启熔炉。
- 若集齐三枚"余火之证"，凭证会在炉心前共鸣，解锁"以身代炉"的真结局选项。

## 5. 结局与后日谈

| 结局 | 条件 | 过程 | 结果 |
| --- | --- | --- | --- |
| A. 熄灭熔炉 | 默认 | 主角拔出炉心，积压的记忆一次性回流 | 烬民短暂恢复清醒后随岛屿沉没；封印松动，"无光者"在海底睁开眼（续作伏笔）；主角无面地离开 |
| B. 重启熔炉 | 首次通关后可选 | 把炉心放回原位，吸收残余余烬 | 回环继续，主角成为新的守炉人，逐渐失去自己的名字；解锁熔炉热度与后续难度 |
| C. 以身代炉 | 集齐 3 枚余火之证 | 主角走进炉心，以自己的火种替代炉心 | 回环终止，烬民恢复名字与死亡；墨蛾带着主角的故事离岛；炉妪第一次叫出"燧"；祭坛空了，只剩一点火星 |

后日谈设计：

- 通关任意结局后，祭坛的对话随结局变化，NPC 会记得玩家选择。
- 热度模式在剧情上是"回环加深"：敌人更强，NPC 也会说出平时不会说的话。
- 图鉴 100% 后解锁一段隐藏文本：墨蛾写下的《余烬行者纪事》，补全主角真名与炉妪的过去。

## 6. 叙事方式与对白样例

叙事原则：

- **环境叙事优先**：烬民重复的动作、墙上的刻痕、钟楼的日期、祭坛的死亡计数，都是剧情。
- **短对话**：NPC 每次回归只说 1–2 句，随进度与死亡次数变化，不做长过场。
- **物品文本**：装备、遗物、记忆碎片附带短背景，拼出世界观。
- **Boss 台词**：每个 Boss 战开场与转阶段各 1 句，强化角色而非打断节奏。
- **死亡是剧情**：死亡次数会影响 NPC 台词、祭坛刻痕和部分场景演出。

对白样例：

- 炉妪（初次）："又醒了？别愣着，炉子不等人。"
- 炉妪（死亡 10 次后）："你的名字……我明明记得的。算了，不重要。"
- 墨蛾（初次）："你身上有灰的味道。活人，死人，还是别的什么？"
- 墨蛾（第二幕后）："你每死一次，我就多一页名字。你猜，今天少了谁？"
- 拾荒商："活人？稀客。死人我见多了，会砍价的死人你是头一个。"
- 守门人（战前）："往上走可以。先告诉我——你是第几个我？"
- 守夜者（战败后）："别用那种眼神看我。我只是……先走了一步。"
- 炉妪（结局 C）："燧。……对，你叫燧。"

## 7. 主题与基调

- **主题**：记忆与身份、牺牲与延续、循环与自由、成长的代价。
- **基调**：悲凉但不绝望；火光带来温暖；拾荒商提供克制的黑色幽默；恐怖元素点到为止。
- **视觉叙事**：用重复动作的烬民表现"被困住的人"，用钟楼刻痕表现"被消耗的历史"，用无面雕像表现"被遗忘的名字"。
- **内容边界**：不做过度的血腥表现，不影射现实宗教与历史，全部角色与名词原创。

## 8. 剧情与玩法系统的结合

| 系统 | 剧情解释 |
| --- | --- |
| 死亡与重构 | 死亡是正典；每次死亡会在原地留下回声，并推进 NPC 台词 |
| 余烬（局外货币） | 被烧掉的记忆灰烬；强化=主角"记起"战斗本能 |
| 武器装备 | 武器记忆：火种读取武器上的使用记忆，解释随机掉落与即时上手 |
| 词缀 | 记忆残留：同一武器因承载的记忆不同而呈现不同特性 |
| 余火之证 | 三个 Boss 各持一枚，是通向真结局的钥匙 |
| 熔炉热度 | 回环加深；敌人与 NPC 都"记得"更多次循环 |
| 图鉴 | 墨蛾收集的名字与故事；100% 解锁隐藏文本 |
